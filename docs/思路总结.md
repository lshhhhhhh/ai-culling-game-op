# 思路总结：视频模型做不好的镜头，怎么做

AI 版《咒术回战》第三季「死灭回游」前篇 OP：角色换成各家大模型的拟人 AI 娘和几位 AI 圈企业家的卡通形象，原曲、节奏和分镜不变。

这支 OP 切换极快、意识流画面多、画风杂，一开始只当作技术探索。做下来最大的收获是：**不要把每个镜头都交给视频模型**。很多镜头换个思路，用生图模型加几行代码，反而又快又稳。

## 一、先看原片在动什么，再选工具

视频模型擅长的是“有表演的人”：人物在动、镜头跟着动、动作和情绪都要保留。它不擅长两类镜头：

- **画面本身没动，是镜头在动**：摇镜头扫过一幅画，推镜头推进一张画。视频模型会给画里的人加动作，或者让画面变形。
- **人没动，只有局部在变**：人物定格，周围有火、雾、贴纸在变。视频模型会让定格的人动起来，或者干脆照抄原片。

所以每个镜头先用代码测一下原片的运动（相邻帧的位移、缩放、逐像素差值），再按运动类型选做法：

| 原片在动什么 | 做法 |
|---|---|
| 一张画在平移、放大（摇镜头、推镜头） | 拼回整张画 → 生图模型重画一次 → 代码按原来的镜头运动重新“拍”一遍 |
| 静止画面、一拍二、一拍三 | 每张画用生图模型改一次，按原长度定格 |
| 人不动，只有局部在变 | 以第一张为准，只在原片真正变化的地方换成逐帧的画 |
| 远处很小的人群 | 画一组动作循环，按原片里每个人的位置贴上去 |
| 物体飞过、落下 | 用干净的背景抹掉原物体，按它的位置和大小贴新物体 |
| 真正有表演的人物 | 视频模型 |

## 二、把“一张画”当成一张画来做

这是这次最有用的思路，第一次用在 040。

原片里乙骨在一幅浮世绘风格的画中，镜头沿着画往上摇再往下摇。整个镜头其实只有**一张画**，动的只是镜头。

1. **还原整张画**：测出相邻帧的位移，把所有帧按位移叠起来，拼回完整的长画。再把拼好的画按轨迹切回去、和原帧比，确认误差很小，说明真的是“一张画在平移”。
2. **重画一次**：把整张画交给生图模型，只换人，画风不变。
3. **重新拍一遍**：代码按测出的轨迹逐帧裁切。

这样做出来的镜头完全稳定，没有视频模型常见的抖动和变形，画质是生图模型的画质。同一个思路可以推广：

- **推镜头**：测缩放而不是平移，把各帧缩回原尺寸叠起来，越近的帧补越多细节，拼出一张高清图，再按缩放重新推一遍。
- **减速、停顿**：逐帧累加实际位移，不用平均速度，原片的节奏就原样保留。
- **光线变化**：画面重画后，再用代码按原片每一段的光线重新打光。
- **原创镜头**：原片太难换的镜头，可以干脆自己设计一幅画，再用同样的方式“拍”出来。

## 三、静止和局部变化：生图加合成

**一致性是关键。** 每一帧单独生图，细节都会有出入（衣服褶皱、字的大小、手的位置），连起来就会“抖”。解决办法：

- **人不动**：每张都以第一张为参考来画；合成时，原片里没变过的地方一律用第一张，只有原片真正变化的地方（火苗、雾、新贴上的卡片）才换成这一帧的画。
- **人在动**：一张接一张画，每张都以上一张为参考，照着原片那一帧的姿势改。
- **只贴回改动的部分**：生图模型改图时整张都会轻微漂移，所以只取它和底图差别明显的区域贴回去，其余像素保持原样。

**新角色和原角色轮廓不一样时要单独处理。** 比如新角色多了长马尾、尾巴，这些部分在原片里是背景，判断“这里有没有被雾吞掉”时不能看原片，要看生成的那张画。

**拼贴镜头**：每张后贴上去的卡片，用它出场那一帧和前一帧的差来测位置，测一次以后固定。如果和整段的第一帧比，会把原角色的嘴、线条和卡片里的闪烁一起抠出来。

**全代码特效也是一个选项。** 光柱改色、发光纹路、卷积网络的特征图面板这类东西，直接用代码画，比让模型“理解”更可控。

## 四、用视频模型时的思路

**1. 关键帧改的是自己的输出，不是原片**

先跑一次，看哪里不对（发饰扭曲、体型不对、配色不对、手画坏）。从生成结果里挑几帧，让生图模型只改坏掉的那一处，再作为定时关键帧重跑。比反复改提示词稳定得多。只有整体画风跑偏时，才回到原片的帧上改。

**2. 模型照抄原片时，拿自己的上一版当参考视频**

有时关键帧完全不起作用，模型照抄原片，连之前换好的人也退回去了。这时不再用原片作参考视频，而是用自己上一版的输出：换对的部分已经在参考里，模型只需要改剩下的那一处。

**3. 不要在提示词里规定动作**

想把下落的炸弹换成显卡，一开始在提示词里写“旋转”，结果原片其实是“翻转”，自己描述错了。更好的做法是把显卡当成一个角色、给它一张参考图，提示词里不写动作，动作完全交给原片。

**4. 特殊配色先改参考图**

模型会照搬参考图的配色。红黑单色的镜头，用彩色参考图加“红黑”提示词，出来是灰蓝色；先把参考图转成同样的红黑渐变，人物才融得进去。

**5. 文字永远后期加**

模型会把字弄乱。片名、闪字都是先让模型生成无字的画面，再用代码叠字。

**6. 太长的镜头分段**

超出显存的长镜头，只生成人物出场的那一段，前面用原片淡入；局部出问题，就只重做那一段，首尾用已有的帧锚定，再接回去。

## 五、混合：模型给连贯，代码给可控

有些镜头两种方法单独用都不完美。人物定格、被红雾一块块吞没的镜头就是这样：

- 生图加合成：人设和雾的节奏都对，但每张画的明暗不同，合起来会闪。
- 把这个合成版当参考视频交给视频模型：动画连贯、不闪了，但人物画回了原色，有的部分一直没被吞掉。
- 最后在模型的结果上用代码修：从原片学出它的配色，把偏离的颜色压回去；按原片里雾到达各处的先后顺序，让人物一块块消失。

模型负责“连贯”，代码负责“对齐原片”。

## 六、什么时候该换方法

- **同一种方法失败两次，就换路线**，不要继续调提示词。有个镜头让视频模型试了三次都退回原角色，最后换成逐帧生图才解决。
- **挑帧要看画面，不能只看数字。** 差值数字显示“换好了”的帧，实际只换了头，身子还是原角色。
- **对照设定图检查全身。** 只核对上半身，漏掉了下半身穿错的裤子。生图提示词要把每件衣服写到鞋。
- **先复核分镜。** 自动检测的切点有误判，把一个连续推镜头当成两个镜头，结尾就会跳一下。
- **生图模型的安全过滤**：被拒时改内容（比如加一条连裤袜），不要换说法绕过。

## 七、工程上的小经验

- **验收页加“待推理”状态**：方案定了、排在队列里等跑的单元，和“待确认”的成品分开显示。
- **夜间队列可以插队**：每跑完一个单元就重读任务表；显卡降温到阈值以下才提交下一个。
- **拼接成片不要依赖时间戳**：各片段的时间戳衔接不齐时，ffmpeg 的 concat 加固定帧率会悄悄丢帧。逐段解码成原始帧、送进同一个编码器最稳。成片和原片等长时，音轨直接原样拷贝原片，不重新编码。
